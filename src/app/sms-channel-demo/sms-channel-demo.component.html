What's New?

Validation Rules:

  • Channel ID is required
  • Message must have either content OR attachments (or both)
  • Text content is now optional when attachments are provided
  • Each attachment must have: fileName, fileType, fileSize, and fileUrl

Example Payloads:

1. Attachments Only (NEW - No placeholder text needed!):
{{ '{' }}
  "channelId": "sms_sinch-sms_919930349978",
  "attachments": [
    {{ '{' }}
      "fileName": "document.pdf",
      "fileType": "application/pdf",
      "fileSize": 1024,
      "fileUrl": "https://example.com/document.pdf"
    {{ '}' }}
  ]
{{ '}' }}
2. Text Only:
{{ '{' }}
  "channelId": "sms_sinch-sms_919930349978",
  "content": "Hello, this is a message"
{{ '}' }}
3. Text with Attachments:
{{ '{' }}
  "channelId": "sms_sinch-sms_919930349978",
  "content": "Please review",
  "attachments": [...]
{{ '}' }}
