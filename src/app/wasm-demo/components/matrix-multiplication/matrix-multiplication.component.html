🔢 Understanding Matrix Multiplication

How Matrix Multiplication Works

▼

Matrix multiplication is a fundamental operation where each element is calculated by the dot product of corresponding row and column.

Mathematical Formula:
[a₁₁ a₁₂]
[a₂₁ a₂₂] × [b₁₁ b₁₂]
[b₂₁ b₂₂] = [c₁₁ c₁₂]
[c₂₁ c₂₂]
Where each element is calculated as:
c₁₁ = a₁₁×b₁₁ + a₁₂×b₂₁
c₁₂ = a₁₁×b₁₂ + a₁₂×b₂₂
c₂₁ = a₂₁×b₁₁ + a₂₂×b₂₁
c₂₂ = a₂₁×b₁₂ + a₂₂×b₂₂
Computational Complexity:
Time Complexity: O(n³) For n×n matrices, requires n³ multiplications

About This Benchmark

This benchmark compares the performance of matrix multiplication implemented in pure JavaScript versus WebAssembly compiled from AssemblyScript. The test measures the time taken to multiply two square matrices of the specified size for the given number of iterations.

Tips:
  • Try different matrix sizes to see how performance scales
  • Smaller matrices may favor JavaScript due to call overhead
  • Larger matrices typically show WebAssembly advantages
  • Multiple iterations provide more accurate averages
