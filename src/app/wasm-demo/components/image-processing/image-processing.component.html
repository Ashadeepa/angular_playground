🔧 How WebAssembly Image Processing Works

1

📁 Image Upload

User uploads image file → Drawn to HTML5 Canvas → Extracted as raw RGBA pixel data

ctx.getImageData(0, 0, width, height)
2

🔄 Binary Conversion

ImageData contains Uint8ClampedArray of RGBA bytes → Each pixel = 4 bytes (Red, Green, Blue, Alpha)

const {{ '{' }}width, height, data{{ '}' }} = imageData
3

💾 WASM Memory Allocation

Allocate source and destination buffers in WebAssembly linear memory

srcPtr = 1024; dstPtr = srcPtr + imageSize
4

⚡ Data Transfer

Copy binary pixel data directly to WASM memory for zero-copy processing

srcArray.set(data) // Key conversion step!
5

🚀 WASM Processing

WebAssembly functions process raw binary data at near-native speed

wasm.grayscale(srcPtr, width, height)
6

🖼️ Result Display

Convert processed binary data back to ImageData → Display on Canvas

new ImageData(resultData, width, height)
